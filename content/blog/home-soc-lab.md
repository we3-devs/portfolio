# Setting Up a Home SOC Lab

Building a Security Operations Center (SOC) lab at home is one of the best ways to gain hands-on experience in cybersecurity. This guide will walk you through the entire process.

## Prerequisites

- A computer with at least 16GB RAM
- VirtualBox or VMware
- 100GB free disk space
- Basic Linux knowledge

## Step 1: Set Up Your Base Environment

Start by installing VirtualBox and creating a base Ubuntu Server VM.

## Step 2: Deploy SIEM Solutions

Install and configure Wazuh or ELK Stack for log aggregation and analysis.

## Step 3: Add Security Tools

Deploy Kali Linux for attack simulation and configure detection rules.

## Step 4: Create Detection Scenarios

Set up realistic attack scenarios to test your monitoring capabilities.
